# Simply The Best Drywall (site)

Real site for Ray Abreu's drywall repair business, Elk Grove CA. The **Raking Light** direction (Option B, round 2) built out into its own project and repo: `getsumactright/simply-the-best-drywall`, served by GitHub Pages.

The client design workspace (`../Simply The Best Drywall/`) still holds all 11 demos including the original Option B at `round-2/b-raking-light/`. Leave those alone; this folder is the one that evolves.

- Static HTML/CSS/JS, no build step. Preview: `python3 -m http.server 8850`.
- `PRODUCT.md`/`CONTENT.md` in the workspace folder are the brief and the source wording. Resolve disagreements against them. Nothing goes on the site as fact unless it is in CONTENT.md or Ray's Yelp listing.
- Imagery rule: all proof is Ray's real work. The `tex-*.webp` textures are generated examples, labelled as such.
- Contact form has no endpoint yet (falls back to a text message). See README "Before launch".
- Site is `noindex` while staging; see README before launch.
